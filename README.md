# 🚀 Space_Shooter_UNIR
Proyecto desarrollado en Unreal Engine como parte de la asignatura de Programación y Arquitectura de Videojuegos. 

## Descripción
Space Shooter en 2D donde el jugador controla una nave espacial y debe sobrevivir el mayor tiempo posible eliminando enemigos.

## 🕹️ Controles
* Movimiento: WASD o flechas
* Disparo: Spacebar
* Salir al menú: ESC

## Características
* Sistema de dificultad progresiva
* Dos tipos de enemigos
* Sistema de vida con UI
* Power-ups:
  * Escudo
  * Curación
  * Triple disparo

## Contenido
* MainMenu (nivel de inicio)
* MainMap (nivel jugable)
* Blueprints del jugador, enemigos y power-ups
* UI integrada
